#  Ecommerse website

Fashion website built with HTML, CSS and Vanilla JavaScript

## Features

- Dynamic Shopping Cart: Handels shopping cart in real-time.
- Dynamic Search: Filter products by title in real-time as user types.
- Dynamic Product page: Generates detailed product views dynamically based on the selected item.
- Login Simulation: Basic login functionality to demonstrate user session handling.
- Persistent Storage: localStorage
- Form Validation
- Asynchronous Flow: Seamless API integration using fetch and async/await.
